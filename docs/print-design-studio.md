# Print & Design studio: first layout pass

Source tools were imported from `origin/prints-and-design` at `8635557e60df341be1b1ff435a492816670b913a`. The old garment pages and assets were not merged wholesale. The redesigned Artwork & Graphics section applies the imported tools to the current T-shirt (and other existing garment previews).

## Layout decisions

The existing Ceriga sidebar hosts six tool families: Draw & paint, Shapes & paths, Typography, Artwork library, Patterns & repeats, and Wear & texture. Lucide icons match the site's existing icon language. The white canvas has Select/Draw/Erase controls, garment side controls, and small selection actions. The right inspector separates tool creation, selected-object properties, and layers. Text content, font, size and appearance take precedence over printing method and advanced transforms. Specialised settings use collapsible sections.

The brush library uses actual strokes generated by the imported brush engine, searchable by name and grouped by medium, including textile-specific thread brushes. It retains all 41 source presets. The phone inspector is persistent and collapsible so the canvas stays visible. A stable 800 by 700 design coordinate space prevents reflow from relocating artwork when panels or device sizes change.

The source engine and advanced controls remain available: drawing/erasing, shape paths, custom areas, text curves/effects, patterns, distressing, image adjustments/filters, crop/warp/distortion, editable groups, merging, uploads, and asset workspaces. Studio artwork is saved in `BuilderState.studioArtwork`; existing prints are used as the starting point when the field is absent. This first phase does not claim that every inherited tool, manufacturing export, or non-studio project preview has been audited. Connecting the expanded artwork model throughout review/export and resolving inherited functionality gaps remains the next phase.

## Usability redesign

The initial layout reused too much of the old inspector. The revised interface separates creation from selection editing, with a persistent visual layer dock and an independent brush-tuning view. Everyday controls use shared, labelled fields and consistent selected states. The canvas owns direct actions; the inspector owns adjustment. Deeper controls are grouped by their purpose rather than collected into a default scrolling form.

Ceriga principles used here: keep the garment visible; show visual choices before technical fields; give each task one obvious starting point; retain editing context; preserve editable sources; make advanced options discoverable without placing them ahead of the basics. Medium categories, actual stroke previews, saved brushes, real text presets, filtered pattern previews and artwork thumbnails support these principles. Create/Edit labels accompany icons. V/B/E select the canvas tools and F toggles focus, without intercepting typing in form fields.

Behaviour checks include same-tool navigation after selecting artwork, committed numeric input, brush/settings navigation, selected text properties, category filtering, and layer access. Image filters, custom repeats, font imports and original advanced tools remain available in context.


### Clean workspace refinement
The default inspector shows one tool family. Brush medium and visual strokes replace the old stacked toolbar; brush settings open separately. Layers stays collapsed until requested. The canvas has no duplicate tool rail or selection action strip. Typography presets, stroke tuning, texture, dynamics and other advanced controls are disclosed on demand. Shapes start with nine essentials and patterns with six previews. Shared control styling uses a consistent type scale, restrained section dividers, custom range tracks, visible keyboard focus and compact value badges. Desktop and phone keep the garment on the canvas.
