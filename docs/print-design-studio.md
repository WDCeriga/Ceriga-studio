# Print & Design studio: first layout pass

Source tools were imported from `origin/prints-and-design` at `8635557e60df341be1b1ff435a492816670b913a`. The old garment pages and assets were not merged wholesale. The redesigned Artwork & Graphics section applies the imported tools to the current T-shirt (and other existing garment previews).

## Layout decisions

The existing Ceriga sidebar hosts six tool families: Draw & paint, Shapes & paths, Typography, Artwork library, Patterns & repeats, and Wear & texture. Lucide icons match the site's existing icon language. The white canvas has Select/Draw/Erase controls, garment side controls, and small selection actions. The right inspector separates tool creation, selected-object properties, and layers. Text content, font, size and appearance take precedence over printing method and advanced transforms. Specialised settings use collapsible sections.

The brush library uses actual strokes generated by the imported brush engine, searchable by name and grouped by medium, including textile-specific thread brushes. It retains all 41 source presets. The phone inspector is persistent and collapsible so the canvas stays visible. A stable 800 by 700 design coordinate space prevents reflow from relocating artwork when panels or device sizes change.

The source engine and advanced controls remain available: drawing/erasing, shape paths, custom areas, text curves/effects, patterns, distressing, image adjustments/filters, crop/warp/distortion, editable groups, merging, uploads, and asset workspaces. Studio artwork is saved in `BuilderState.studioArtwork`; existing prints are used as the starting point when the field is absent. This first phase does not claim that every inherited tool, manufacturing export, or non-studio project preview has been audited. Connecting the expanded artwork model throughout review/export and resolving inherited functionality gaps remains the next phase.

## Research informing the interaction model

- Adobe Photoshop workspace and contextual controls: https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/workspace-overview.html
- Procreate brush libraries, mediums and stroke previews: https://help.procreate.com/procreate/handbook/brushes/brush-library
- Figma's selection-aware properties panel: https://help.figma.com/hc/en-us/articles/360039832014-Design-prototype-and-explore-layer-properties-in-the-right-sidebar

These inform discoverability and focus, rather than reproducing another product's interface. The visual styling, navigation and garment-specific grouping use Ceriga's existing design language.
